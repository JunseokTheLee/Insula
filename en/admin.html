Visitors

Browsers that opened the site, counted once per day (Asia/Seoul) per browser; a member is a browser with a signed-in session at that moment, everything else is a guest. Two devices count twice, a guest who signs in the same day counts once on each side, and visitors without JavaScript and known crawlers are not counted. Recorded by record_visit() from supabase_visit_stats.sql — the "Count visitors" option below switches it off. New artworks and new members come from the existing tables — artworks count the original only, never the pieces it was cut into.

Not available yet — run supabase_visit_stats.sql in the Supabase SQL editor.

Monthly egress cannot be read from the database, so it is not shown here — see the Supabase dashboard → Reports → Usage (250 GB/mo on Pro).

Campaigns

Create a new one from the campaign list

Edit changes a campaign's title and description; its size and reference image are changed with Reshape on the campaign page. Create grid image appears only on campaigns made before the grid-image cache existed: it renders the cell colors into a small PNG once, so their pages stop reading every cell from the database. Deleting a campaign never deletes artwork — every piece returns to its artist's pool. Archived versions are removed together with their live campaign.

Artwork pieces

When an artwork is uploaded the browser cuts it into the piece grid set under "Site options", and only pieces whose colour matches an open cell go into a mosaic. Artwork without pieces (uploaded before this existed, or whose cut failed) gets them with "Cut pieces" — an artwork still placed whole is released from its cell and re-placed as pieces. After changing the grid, "Recut all" cuts every artwork again at the new size.

Not available yet — run supabase_mosaic_pieces.sql in the Supabase SQL editor first.

Artwork thumbnails

When a piece is uploaded the browser makes a thumbnail (longest side 480px; an original that small is used as is) and a micro thumbnail (16×16, for the campaign grid). This shows how many pieces are missing either one; Rebuild thumbnails reads those originals and makes what is missing, one piece at a time. The artwork itself is never changed.

Not available yet — run supabase_mosaic_micro_thumbs.sql in the Supabase SQL editor first.

Admins

Admins can't be granted or revoked from the site (by design). Run this in the Supabase SQL editor:

update public.profiles set is_admin = true where lower(username) = lower('username');

Upload block

Find an account by username to block its uploads. A blocked account cannot upload new artwork (an insert trigger on the server refuses it); what it already uploaded, and the account itself, stay untouched. Use it when deleting alone does not stop the flood.

Not available yet — run supabase_admin_moderation.sql in the Supabase SQL editor first.

Push notifications

Delivers like / comment / reply / follow notifications while the app or browser is closed. Before switching it on: run supabase_push.sql, generate a key pair with node tools/generate-vapid-keys.js, paste the public key below, register the private one as a Supabase secret, and deploy the push Edge Function. While either field is empty no "Get notifications" button appears in the notification panel.

The private key goes neither in this repository nor on this screen — it lives only as a Supabase secret.
